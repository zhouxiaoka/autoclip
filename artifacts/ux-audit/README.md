# 当前界面核对辅助环境

`preview.mjs` 启动产品现有前端组件，使用只读示例 API。仅用于核对布局和可达入口，不是新产品设计或真实运行后端。

- 地址：`http://127.0.0.1:3011`
- 示例：一个已完成项目、两个无媒体切片、一个合集。
- 所有非 GET API 请求返回 405，防止执行导入、生成、保存或删除。
- 不加载环境密钥，不连接用户数据库。不能用此环境验收视频播放、模型调用、渲染或数据持久化。
- 需要已安装 frontend/node_modules；本次核对临时用软链接复用原工作区依赖，检查完成后已移除链接。
- 启动：`node artifacts/ux-audit/preview.mjs`。

现状分析见 `docs/CURRENT_UI_INTERACTION_AUDIT.md`。
