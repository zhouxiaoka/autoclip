# 游戏买量 Golden Case 库 v0.1

研究日期：2026-09-21。首批方向：超休闲/休闲闯关、竖屏视频。由产品研究主动找案例，不以用户提供参考片为前置。配套机器可读记录：[registry.json](golden_cases/registry.json)。

**目标是找到有真实投放效果且能持续起量的具体视频。** 本轮已定位 2 条官方效果案例关联的视频、1 个有规模数据的广告活动。它们可以用于创意研究；尚无一条同时取得“具体视频、该视频效果、该视频规模”完整证据，严格 `golden_verified` 当前为 0。这个缺口保留为验收项，不用播放量或整个活动的成绩补齐。

## 2. 视频关联、可观察内容与证据缺口

### REF-001：优先研究 Deliver It 3D

已在官方页面 DOM 中核对：视频 ID `7137293574655298818` 位于 Voodoo 案例标题下。打开嵌入页可见人物与游戏分屏、英文解说字幕；本轮只核验到封面/首帧，未成功完整播放，不能据此填写时长、逐秒分镜或声音节奏。官方说明的实验方向是给玩法加入真人解说。

尚缺：该条视频的安装量/花费、测试周期、地区/系统、对照组细节、归因窗口及留存/ROAS。公开相对提升不能外推为本产品的收益预期。

**产品假设（待验证）：** 先让观众理解目标和行动，再用解说放大情绪，可能比只截取刺激动作更适合买量。转化为 Seed 的检索需求：找到“目标可见—操作可读—反馈明确”的连续素材，并指出需要解释的地方。首版可先测试画外旁白，不把真人出镜制作纳入必要能力。

### REF-002：Idle Green Button

已核对官方案例标题与视频 ID `7123190250054159617` 的页面关联。未完成视频播放与逐镜头核验；不预填视觉、音频或时间标注。数据仍是创意实验案例层级，缺少单条消耗和安装规模。

用于验证“解说让简单玩法更可理解”是否值得跨游戏测试。它与 REF-001 属于同一创意方向，不能当作三种不同模板已获得验证。

### REF-003：Attack Hole

官方同时披露了 500 多条创意和额外 250 多条创作者素材的生产策略。这支持持续迭代与本地化的必要性，但无法将整个活动的安装量分配到任一条视频。当前没有建立具体视频到效果数据的映射，不纳入单片质量评测。

产品映射：保留创意 ID、钩子/语言/声音版本及结果，支持有目的地做变体。此映射是产品推断，不是对所有创意都有效的因果结论。

## 3. 如何继续找到正在起量的视频

使用“双向查证”：从好数据反查视频，也从榜单视频反查数据；只有证据可关联时合并。

1. **效果案例入口。** 检索平台、发行商、制作方的一手案例，组合游戏名、`creative`、`CPI`、`IPM`、`ROAS`、`installs`、`case study`。先判断视频/静态图/Playable、单条/广告组/活动，再提取数字；本轮 REF-001–003 由这条路径获得。
2. **正在投放的候选入口。** TikTok Top Ads 按游戏、地区、安装目标和可用时间范围筛选；分别查看 CTR、CVR、Reach，记录平台实际显示的单位和分位。先覆盖最近 30 天，再扩大至 90 天；这是搜索窗口建议，不假定界面必有这两个快捷选项。平台支持的筛选、排序和逐秒相对表现见[官方操作说明](https://ads-useast2a.tiktok.com/resources/help/article/how-to-use-the-top-ads-dashboard)。未登录只展示有限结果，本轮没有获得完整榜单样本。
3. **精确匹配。** 用视频 ID/广告 ID/同版本文件对应案例；相同游戏、相似封面、同一账号都不够。改过开头、语言或时长的素材作为不同版本。第三方广告情报的估算曝光、运行天数仅用于发现候选。
4. **补规模与效果。** 优先找直接披露该素材数据的案例；如果公开信息不足，保持候选状态。以后有自有投放数据时，以广告 ID 关联原始导出。未知字段保留空值，不拼接不同来源或不同时间的数字。
5. **完成媒体审阅。** 视频能完整查看后，标注钩子、玩法、行动、反馈、文字、声音、结尾及真实时间边界；无法播放就不能进入逐镜头 Golden 评测集。

推荐首轮发现池目标：20 条同赛道候选 → 6 条效果证据充分的研究参考 → 尽量选 3 条严格 Golden，覆盖至少两种创意结构。数量为工作目标，不能为凑数降低证据标准。当前完成数量以 registry 为准。

## 4. Golden 入库门槛

| 状态 | 要求 | 可以怎样使用 |
| --- | --- | --- |
| `discovery_candidate` | 找到视频或有用案例，但效果/关联未核验 | 搜索线索，不作为成功标签 |
| `case_linked_reference` | 一手效果案例明确关联具体视频，数据范围如实记录 | 研究创意假设，不声称该条已规模化 |
| `campaign_reference` | 一手活动规模与效果，但无单视频映射 | 研究生产流程，不给片段贴效果标签 |
| `golden_verified` | 具体视频可完整审阅，效果与规模都绑定同一版本，口径完整、适用范围明确 | 在该游戏/渠道/受众条件下作为效果对标 |

严格入库同时检查：

- **身份**：视频/广告 ID、版本、语言、游戏、渠道、地区、系统、日期可追溯。
- **效果**：至少一个安装或价值指标（如 CPI、IPM、ROAS）和明确比较基准。仅 CTR 或播放多不足以证明买量有效；缺少安装后数据时，只能标为安装获客有效，不能标盈利。
- **规模**：该版本的曝光/安装/花费及观察周期有直接依据，足以区别偶然的小测试。阈值按游戏经济模型、目标 CPI 和可接受误差提前设定，不杜撰通用“起量线”。
- **可信度**：记录样本量、归因窗口和流量条件；公开案例缺字段则不升级为严格 Golden。实验数据不明时不标统计显著。
- **可迁移性**：同赛道优先；历史、跨渠道、跨地区的胜者只在限定条件下使用。Golden 不等于永久有效或普适模板。

## 6. 进入 AutoClip 的方式

**先建参考库和验收样片，再谈模型学习投放规律。** 当前样本少、历史性强、缺少失败对照，不能据此训练“高转化预测器”。

参考库以 `case_id` 连接证据与创意拆解。拆解中将“观察事实”“模型推断”“待验证假设”分开；效果数字不灌给 Seed 当作待猜测标签。需要同时收集同游戏、相近流量条件的普通/失败创意，控制只看赢家的偏差。

Seed 的首轮检索评测仍使用独立人工标注的真实录屏，考察事件覆盖、因果连续、定位、无事件误报及制作角色。Jev 在相同证据上比较排序与时间成本，不能凭两个公开案例声称能预测转化。

最终验收分开：①同素材人工版与系统版的盲评；②实际投放中同条件对照的效果。参考广告不能提供本产品生成视频的真实投放成绩。

建议每周一次研究更新：增补近期候选、核验失效链接、记录升级/降级原因；每个评测版本冻结案例 ID 和标注版本，新增参考进入下一版，避免边改模型边改考题。此处定义维护流程，未建立自动定时任务。

当前最大缺口是**单条视频对应的规模数据，以及完整播放后的分镜标注**。素材库已建立，但严格 Golden 验收仍待补齐这些证据。
