## 最新报错：#230 / #231

两条反馈均来自 Windows x64、v1.3.5，错误是「本地 Whisper 生成字幕失败」。没有原始堆栈、用户视频或模型缓存，不能确认同一个底层原因。

本次确认并修复：

1. 项目卡已取得 `error_message`，但只用它决定设置按钮与反馈上下文，没有渲染错误正文。现在失败卡展示可选中、复制的正文；成功后不展示旧错误，React 转义错误内容。
2. 模型管理用「snapshots 目录非空」判断已下载。构造缺少 model.bin、配置、tokenizer 或词表的缓存，旧实现全部误报 downloaded；空权重和失效链接也一样。现在要求同一快照内必需文件存在且非空，下载返回后再验证，缺失文件可重新下载，丢失文件后不继续显示 100%。这不是权重内容的哈希校验。
3. 已下载的完整快照直接传给 Whisper，优先 refs/main，其次最近完整快照；兼容旧 large 别名。避免离线转写再次按模型名访问 Hub。无完整缓存时保留原有下载流程。
4. 将运行时依赖、内存不足、下载连接、模型文件、访问权限、音轨解码分成可操作提示；未知失败保留异常类型，不公开原始异常中的本地路径或 URL 凭证。

这两条 issue 继续开放：本分支尚未发布，且没有原报告者 Windows 机器上的完整复测。
