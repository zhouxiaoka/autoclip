## 修复

- **#230 / #231：** 失败卡之前没有渲染已持久化的错误正文，现在显示可复制、转义的错误，并按依赖、模型、内存、网络、权限和音轨提供恢复提示。
- **Whisper：** 不完整缓存不再误报已下载；必需文件须存在且非空，完整快照直接离线加载，兼容 `large` 别名。运行时检查真实导入，避免损坏 DLL 被误判已安装；安装防重入并以 UTF-8 读取 pip 日志。
- Windows 真转写实际复现 **`av.open()` 不接受 `metadata_errors`**。PyAV 19 删除了 faster-whisper 仍使用的参数。新安装约束 `av<19`；已有 PyAV 19 时只对此兼容错误使用本机 ffmpeg 解码为 16 kHz 单声道数组再转写，不改全局 PyAV。上游依据：[PyAV changelog](https://github.com/PyAV-Org/PyAV/blob/main/CHANGELOG.rst)、[faster-whisper audio](https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/audio.py)。这解释了验收环境中的失败，不推断所有历史用户都属于这一根因。
- **#123：** step1 / step5 读取已保存的分块字符数和合集条数，下一次任务生效；字幕块保留完整 cue 和绝对时间。分类提示词要求的 JSON 大纲现在可解析；少于三个但有效的合集不再被丢弃。
- **#197 / #183：** 延续主线链接解析修复，为视频下载加入有限网络/分片重试；字幕下载失败时回退为仅视频，YouTube 格式错误时尝试 HLS。永久错误仍失败，不伪造成功。这不是对任意地区网络或受限视频的可用性保证。
- 真出片发现完成日志读错 step6 计数字段，现与实际产物数量一致。
