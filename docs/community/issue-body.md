# 从 Discussion 晋升为 Issue 时使用的正文

标题用 `[Feature] ` 开头，后面写能力，不写方案口号。

```markdown
## 背景

这条需求为什么值得做。用一两段话转述讨论里的场景。

## 用户场景

谁在什么情况下会碰到。

## 验收

- [ ]

## 相关讨论

- https://github.com/zhouxiaoka/autoclip/discussions/编号

## 不做

这次明确不包含什么。
```

讨论帖里补一条评论，链回这个 Issue，并写上它在路线图的哪一列。
没有人点头之前，列只允许是 Exploring 或 Researching。
