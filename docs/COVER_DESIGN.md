# 自动封面与发布包

在「设置 → 模型 → 封面」选择默认制作方式。原帧排版在本机完成。模型编辑使用已配置的封面模型与参考帧发送权限。模型直接交付带标题的成图。模型未配置、未获帧发送许可或模型结果未通过检查时，产品保留已有封面或从同一真实帧本地排版。

在成片的「发布工具 → 查看封面」编辑标题即可锁定显示文案。选择风格、当前帧、另一个时间点或重选镜头后点击「重新生成封面」。手动与自动成片的封面都由现有任务执行。卡片、下载和同一版本的发布包读取同一产物。

## 设计与记录

- 自动策划对照当前片段的转录提取文字；发布文案供选题参考。缺少依据时使用保守结果，用户明确锁定的文字原样保留。没有证据的身份、动作、事实判断留空。
- 共用的 CoverBrief 记录来源和哈希、选帧时间和候选、批准文案、重点词、字体和颜色、文字位置与换行、编辑权限、输出尺寸。原帧聚焦保留照片主次，文化访谈使用暖色和本机衬线字体，科技提问保留疑问和限定，鲜明态度使用窄粗体容纳英文长词。
- 中文无衬线与英文窄粗体使用已随包提供的 Noto Sans SC 与 Barlow Condensed（OFL）。宋体使用已安装的系统字体，不分发系统字体文件。系统缺少衬线字体时回退，简报记录提示。
- 制作路径使用原图的真实像素或带参考图的有限编辑。OCR 保留大小写、数字、标点和额外文字；一次文字修正仍使用同一帧。模型输出按目标画布等比适配，保留完整图。来源、排字、尺寸、OCR 和视觉复核有各自状态。
- 新产物先写独立版本的封面和参考帧，再原子切换 JSON 索引。旧任务以请求标识失效。发布槽位与各成片版本使用独立索引；旧版参考帧没有时间点时保留未知。
- 本地 JSON 同时包含实际发送的提示词、模型标识、指纹、结果版本、变换记录和降级原因。原帧模式下提示词发送记录为空。源码回归覆盖行为；最终视觉验收由负责人逐张确认。
