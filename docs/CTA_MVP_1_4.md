# 游戏推广 CTA MVP

2026-09-27；独立分支 `codex/game-cta-mvp`，基于未合并的 `codex/promo-auto-aspect`（PR #213）。此 PR 只包含 CTA 增量，合入时先处理依赖链，不直接越过前置 PR 合入 main。

## 已实现

- 编辑器折叠的「行动引导 CTA」：关闭、按时长自动推荐、玩法续播、挑战交接、品牌落版。
- 玩法续播在末镜头最后 3 秒叠加文案；不足 8 秒总长或末镜头不足 4 秒时降级为独立落版，避免与开头包装重叠。
- 挑战交接保留全部镜头后定格 2.5 秒；用户必须确认末镜头完整且适合定格。确认绑定末镜头 ID 与起止时间，换镜头/改边界后回到独立落版。
- 品牌落版追加 2.5 秒独立渐变底板，避免拿任意末帧冒充胜负结果。游戏名可选，缺失时不猜测名称。
- 中/英/日默认行动文案，支持原文自定义、位置调整；自定义文案和游戏名不自动翻译。品牌落版使用固定居中区域。
- 后端版本化 CTA 计划与 PNG 同时用于排版预览及 FFmpeg 导出；草稿保存、另存、导出快照、导出记录沿用原链路。
- 原声保留，追加段填静音；不额外合成音效或重复最后的音频。输出总时长包含追加段。
- 所有旧草稿以及新草稿默认关闭，需要在编辑器开启；不影响原有内容切片与字幕低成本链路，不调用模型。
- 八语界面文案。预览明确标注为文字图层，完整画面与声音需查看渲染结果。

## MVP 范围

自动推荐仅使用现有镜头时长，不宣称识别广告意图、胜负或 HUD 安全区。只有挑战型增加人工结果确认；用户仍需检查所有模板的遮挡与文案。支持修改位置与关闭。

本次不含 Logo/角色资产上传、品牌资料库、投放渠道规格、可点击按钮、HTML5 Playable、活动奖励文案生成或六类完整语义适配。当前是视频内 CTA 基础结构，不是经过投放验证的起量模板。后续以实际样片评审决定视觉升级，不恢复动效字幕排期。

启用 CTA 时增加一次视频编码；旧草稿关闭时维持原流程。品牌/挑战追加段采用固定 2.5 秒作为 MVP 起点，不声称是行业最佳时长。暂无逐帧实时合成预览。
