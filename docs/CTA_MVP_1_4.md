# 游戏推广 CTA MVP

2026-09-27；独立分支 `codex/game-cta-mvp`，基于未合并的 `codex/promo-auto-aspect`（PR #213）。此 PR 只包含 CTA 增量，合入时先处理依赖链，不直接越过前置 PR 合入 main。

## 已实现

- 编辑器折叠的「行动引导 CTA」：关闭、按时长自动推荐、玩法续播、挑战交接、品牌落版。
- 玩法续播在末镜头最后 3 秒叠加文案；不足 8 秒总长或末镜头不足 4 秒时降级为独立落版，避免与开头包装重叠。
- 挑战交接保留全部镜头后定格 2.5 秒；用户必须确认末镜头完整且适合定格。确认绑定末镜头 ID 与起止时间，换镜头/改边界后回到独立落版。
- 品牌落版追加 2.5 秒真实玩法展示：源画面模糊背景、单张玩法画框及行动按钮。不复制镜头凑多格。游戏名可选，缺失时不猜测名称。
- 中/英/日默认行动文案，支持原文自定义、位置调整；自定义文案和游戏名不自动翻译。品牌落版使用固定居中区域。
- 后端版本化 CTA 计划与 PNG 同时用于排版预览及 FFmpeg 导出；品牌预览包含源视频采样画面；草稿保存、另存、导出快照、导出记录沿用原链路。
- 原声保留，追加段填静音；不额外合成音效或重复最后的音频。输出总时长包含追加段。
- 所有旧草稿以及新草稿默认关闭，需要在编辑器开启；不影响原有内容切片与字幕低成本链路，不调用模型。
- 八语界面文案。预览明确标注为排版预览，完整画面与声音需查看渲染结果。

## MVP 范围

自动推荐仅使用现有镜头时长，不宣称识别广告意图、胜负或 HUD 安全区。只有挑战型增加人工结果确认；用户仍需检查所有模板的遮挡与文案。支持修改位置与关闭。

本次不含 Logo/角色资产上传、品牌资料库、投放渠道规格、可点击按钮、HTML5 Playable、活动奖励文案生成或六类完整语义适配。当前是视频内 CTA 基础结构，不是经过投放验证的起量模板。后续以实际样片评审决定视觉升级，不恢复动效字幕排期。

启用 CTA 时增加一次视频编码；旧草稿关闭时维持原流程。品牌/挑战追加段采用固定 2.5 秒作为 MVP 起点，不声称是行业最佳时长。暂无逐帧实时合成预览。

## 视觉修订：以实际案例为基准

首版深色信息卡与抽象底板被用户否定，不能作为视觉验收通过的证据。PR 保持 Draft。

主视觉参考为用户提供的 Royal Match 广告截图：其绿色按钮具有深色底座、蓝色外轮廓、厚绿斜面、浅色高光和粗描边字。画面主体是实际玩法，小卡金边服务于玩法展示。修订稿去除信息卡与装饰短线，使用上述材质层次，并把品牌落版换成真实源画面。没有该游戏 Logo，不复制 Royal Match 商标；只有一个片段时保留一个玩法框。

本轮是“休闲游戏”风格验证，不把绿色按钮自动推广为所有品类的统一风格。用户截图底部的原生安装区域不合成到视频；实际点击仍由投放平台处理。

辅助调研：
- Last Night Media 制作方公开案例 https://lastnightmedia.com.au/mobilegamesexamples ，实看 Royal Match – Turbulence Champion 的 UGC 画面（播放器标示 28.44 秒）；它说明真实案例也存在人物/手机玩法承接，不能全都套固定片尾。该视频不是本按钮的像素参照。
- Liftoff 官方格式示例 https://docs.liftoff.io/liftoff_creatives/ad_formats ，其静态示例是 Liftoff 自身营销演示，不是游戏创意 Golden Case，不用于证明本视觉方案有效。
- AppGrowing 公开 Royal Match 分析 https://appgrowing.net/blog/en/royal-match-ad-creative-analysis-king-in-peril-hooks-and-pick-ctas/ 仅用于理解剧情与 CTA 的承接；未获取广告账户转化数据。

视觉对照检查：按钮体积与高光、粗描边字、玩法面积、真实来源、单片段不凑六格。修订产物另存 `cta-reference-v2/`，与被否定的 `cta-mvp/` 区分；仍等待用户视觉评审，不把回归测试通过当作样式验收。

修订后验证：Studio 与 CTA 后端 106 passed；前端 109 passed、typecheck/lint 通过。品牌预览与真实导出增加像素对照；已重新渲染三份 1080×1920 样片。此前 600 项全量通过对应基础 MVP 提交，不与修订后验证混淆。

## 2026-09-27：CTA 结构与视觉风格分离

- 新增独立 `cta.style`：`glossy`（玩具厚边）、`soft`（轻量休闲）、`tactical`（硬朗任务框）、`type`（无按钮大字邀请）。与 continue/challenge/brand 结构组合使用；旧配置缺失字段时保持 glossy。
- 新增可选 `cta.accent`，支持手动强调色、恢复默认色。预览、保存快照、导出共用同一配置；过暗的任务框/大字强调色会提亮以保留可读性。
- UI 八语文案齐全。明确提示当前手选风格，未声称自动理解画风。现有草稿没有可靠的 UI 材质/画风字段，下一步应在已有视觉分析中采集证据，再提供可校正的推荐；字幕链路不隐式追加付费调用。
- 参考：用户 Royal Match 截图；[制作方公开广告作品](https://www.behance.net/gallery/195249951/Static-Ads-End-Cards-for-Mobile-game-Interstitials)中的 Idle Pizza Shop、Shape Transform、My Dream Hotel 和 Color Water Sort 3D；[COD 制作方试玩广告 UI](https://www.behance.net/gallery/101914157/Call-of-Duty-Mobile-Activision)。后者只支持硬朗视觉语法，不是已验证下载尾卡。未复制第三方 Logo、玩法资产或商店控件；无投放效果结论。
- 真实样片：同一本地跑酷源片取 10–17.5 秒，四款各导出 10 秒（含 2.5 秒尾卡），1080×1920。该样片是控制变量的样式比较，不代表射击风格适合跑酷；跨品类素材适配仍待验收。样片在本机评审页 `http://127.0.0.1:8794/style-samples.html`，不会提交用户视频。
- 验证：Studio/CTA 后端 108 项通过；前端 109 项、typecheck、Lint、build 通过。浏览器实际切换为 tactical、保存 V2、重载确认一致。构建保留已有大包体积提示。
- 待办：风格证据与推荐、真实跨品类对照、模板选择缩略图、文字长短与横竖画幅进一步视觉评审。动效及买量效果验收不在本次完成范围。

## 2026-09-27：完整品牌尾卡（poster）

根据用户反馈，按钮皮肤不等于完整广告模板。本次新增可选 `brand_layout=poster`：名称设计字或用户 Logo、真实源帧主画面、App icon、slogan 和 CTA 组成一张尾卡。仅在解析后的 brand 结构使用；旧布局默认为 classic，历史输出保持兼容。

- 编辑器支持 Logo/icon 文件选择、预览与移除；slogan 原文输出，不隐式翻译。Logo 存在时优先展示，缺失时游戏名使用设计字，未伪称官方 Logo。
- 品牌图片限制为静态 PNG/JPEG/WebP、每张 512 KB、最多 400 万像素。后端验证实际编码和像素，拒绝 URL/SVG/损坏或超限图片；渲染不读取任意路径、不请求外网。
- MVP 图片以受限 data URI 随草稿保存，使复制版本和不可变导出快照自包含。预览响应和导出结果摘要不重复回传图片字段。项目级共享素材库、自动品牌检索/提取仍未完成。
- 实际 1080×1920 样片：复用上轮已保存成片的前 7.3 秒干净玩法区间，加 2.5 秒尾卡，总长 9.8 秒。原 Downloads 文件已移走，未因此重新调用模型。名称来自既有输入记录；icon 来自 [官方商店页](https://play.google.com/store/apps/details?id=com.rioo.runnersubway)，仅用于本地评审，未提交为产品资产。顶部为设计字，slogan“下一次闪避，由你决定”为本次创作文案，不是官方口号。
- 评审入口：`http://127.0.0.1:8794/brand-review.html`，包含前后帧及真实视频。此轮只验完整构图，不声称买量效果或自动素材适配完成。
- 验证：110 项 Studio/CTA 后端、109 项前端、typecheck、Lint、build 通过；真实样片渲染并查看导出尾帧。保留已有构建大包提示。
