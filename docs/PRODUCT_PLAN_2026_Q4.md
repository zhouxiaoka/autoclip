# AutoClip 产品规划：面向游戏买量的多模态创意制作

更新：2026-09-21。当前方向：用户要求尽快接入 Seed 多模态能力、研究 Jev，并将输出质量对标游戏买量素材；用户已提供驾驶、跑酷、合成三类 YouTube 输入；先用跑酷制作竖屏样片，再验证合成与驾驶。正式推广的游戏、受众及投放渠道仍需在制作简报中明确；已自主建立效果案例库，单视频起量证据继续核验。

本文是产品执行规划，未实现模型接入、生成实际样片或创建投放。资源仍按每周 5–10 小时估算。

## 1. 核心目标与首个交付

**把真实游戏录屏转成能看懂玩法、产生尝试欲望、可进入投放测试的视频创意。**

Seed 接入立即开始。高光检索是第一项基础能力，最终交付还包含开头钩子、镜头编排、节奏、字幕、音效、画幅和结尾。Jev 作为可选筛选与评分优化，不阻塞首个样片。

首个产品里程碑：一条通过人工创意评审的基础成片，加两个有明确测试假设的变体；同时保留来源片段、可修改的编辑方案与质量检查结果。

先允许人工参与选镜头和节奏调整。将达到标准的样片流程固化成可重复运行的能力，再逐步提高自动化比例。

## 2. 首批用户与范围

核心用户是有游戏素材、需要持续生产买量创意的小团队或个人。产品任务是减少找素材、试编排和做变体的人工时间，并维持成片完成度。

首批以用户提供的 Subway Princess Runner 跑酷视频为样片输入；Gossip Harbor 合成与驾驶视频进入后续验证。输出以竖屏视频为主，必要时将完整横屏玩法嵌入竖屏布局，保留操作与障碍；暂不预设具体广告平台。已有字幕切片和 CLI/MCP 继续保留，在新制作链稳定后复用其能力。

首版输入：真实录屏、玩法和卖点说明、受众、品牌素材、可用音效；已核对三条实际输入并制定[逐类制作方案](GAMEPLAY_TO_UA_WORKFLOW.md)；制作前确定推广游戏、完整源片事件与视觉参考。初始模型能力实验可用 3 分钟内短录屏，产品样片时长依创意与最终渠道确定。

首版流程：导入 → 填简报 → 查看可用镜头 → 选择创意结构 → 预览整片并修改 → 导出基础片和变体。

## 3. 产品能力分层

| 层次 | 作用 | 本轮交付 |
| --- | --- | --- |
| 素材理解 | 看懂玩法、状态变化、关键动作和结果 | Seed 多模态接入、证据时间段、无字幕路径 |
| 创意编排 | 将镜头安排成有动机和反馈的完整广告 | 钩子—挑战—行动—反馈—收尾；每段对应原片证据 |
| 确定性制作 | 把方案稳定渲染成片 | 剪辑、必要变速、画幅、文字、声音、尾卡 |
| 质量与筛选 | 发现重复、缺失、信息不清和制作问题 | 规则检查 + 模型辅助 + 人工整片评审；Jev 对照实验 |
| 变体与反馈 | 用更少时间测试新开头和节奏 | 一条基础片 + 两个变体、创意 ID、人工导入投放汇总 |

Seed 负责视觉事实提取，可分阶段参与创意规划。Jev 当前官方文档只支持文本与文本化结构状态，因此评估已提取证据和方案，不承担直接视频理解或最终成片视觉审核。[Jev 官方输入说明](https://docs.typesafe.ai/concepts/state)

## 4. 六周交付顺序

每周只推进一个主开发主题。必要可靠性与回归随该主题完成；监控、更新器、账号系统不成为原型前置。

| 时间 | 主主题 | 可验收结果 |
| --- | --- | --- |
| W1：09-21—09-27 | Seed 视觉原型与样片标准 | 模型权限/素材就绪后争取 72 小时首个候选结果；成功、失败、无高光三类素材基线 |
| W2：09-28—10-04 | 第一条验收样片 | 从一种素材最充分的创意结构出发，人工参与完成整片并记录修改；以买量完成度评审 |
| W3：10-05—10-11 | 可重复的创意制作 | 将样片拆成带原片引用的编辑方案，支持重现、改开头、换镜头与重渲染 |
| W4：10-12—10-18 | 两个变体与 Jev 对照 | 保持主要内容不变，测试开头或节奏；同证据比较规则/Seed/Jev 的时间与质量 |
| W5：10-19—10-25 | 成片质量和素材复用 | 修最大质量短板，复用事件缓存，人工对照制作时间与成片接受率 |
| W6：10-26—11-01 | 复用反馈与下一轮决定 | 有投放授权及条件时取真实反馈；否则完成创意验收，明确未验证效果；决定是否扩第二场景 |

这是内部目标。每周只有 5 小时就优先样片与可重复制作，顺延 Jev、缓存及扩场景；不降低成片验收标准来维持功能数量。第一周原型成功不等于买量系统完成。

## 6. 什么才算质量达标

首先确保事件、时间、因果和画面正确。再对完整成片评审：开头是否吸引、玩法是否清楚、节奏是否推进、结果是否有反馈、字幕/音效/画幅是否完成、结尾是否自然。

首个版本目标是达到“可进入小规模投放测试”的制作标准。可通过与同素材人工版本、同赛道参考片的并排评审验证。投放有效必须有真实数据，不能用模型评分或高光准确率替代。

每周核心指标：通过创意验收的成片数、每条通过验收所需人工时间、修改原因、变体生产时间、下一次真实任务复用。检索召回与误报作为上游诊断指标继续记录。

有投放数据后再比较早期观看、完播、点击、安装成本、留存和 ROAS；结合渠道、受众、预算和归因窗口判断，不只看 CTR。

## 7. 更新与传播节奏

每周一个真实案例：原始素材 → 创意目的 → 编排/制作 → 最终成片 → 人工修改或已知问题。以完成样片与质量改善为更新主题。

争取每 1–2 周一个通过验收的小版本；无可发布版本时分享案例或实验结论。第一条内容说明“怎样做出一条买量测试素材”，后续展示改钩子、改善节奏、同素材做变体和实测对照。

发布状态区分已发布、测试中、探索中；未经投放的样片标为待测试创意。持续更新不靠夸大模型倍数和未经验证的转化收益。

## 8. 暂缓范围

暂缓完整时间线编辑器、任意游戏支持、自动投放、Playable 广告、团队协作、账号积分与大规模云端视频处理。首版通过结构化方案与少量可编辑项完成高质量制作，不重建专业剪辑软件。

素材不足时输出补录建议。生成镜头、人物口播等能力等有明确创意需要再加入。商业化在出现稳定重复制作需求、可估算单位成本及付费意愿后推进。
