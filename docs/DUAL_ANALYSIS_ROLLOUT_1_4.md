## 固定产品约束

底层保留字幕分析和视觉分析两条链路，入口/确认/项目/编辑/包装/导出共用。用户偏好为“字幕分析·低成本 / 智能选择 / 视觉分析”。模型具备多模态能力仅代表可用，不代表已授权每次调用。

- 老用户缺少新偏好字段时默认为字幕分析；单独保存视觉配置不改变偏好。
- 新用户引导可以推荐智能选择，用户接受后保存；仅有文字模型仍可完成字幕工作流。
- 字幕模式的导入初筛、推荐、正式分析均不得调用视觉接口；先检查字幕/本地转写能力，缺失时说明下一步，保留素材。仅文字模型配置足够，但无字幕源仍需要可用转写或用户提供SRT。
- 智能选择先使用来源信息、字幕是否可用、画幅与用户要求；如需付费视觉初筛，须提前说明并由用户启用有界初筛。不能为了判断是否用视觉而偷偷调用视觉模型。
- 确认页显示推荐处理方式、依据、模型以及已知成本信息。没有可靠用量估计时不展示虚构金额。允许改处理方式/取消制作类型；正式理解仍需显式确认。
- 视觉不可用或不适合时明确提示，不静默升级模型或切到另一条付费链路。字幕分析不承诺识别无对白游戏动作。
- 内容切片/精彩高光/推广草稿是输出类型，字幕/视觉是分析方式，不能共用一个枚举。模板、构图、字幕、编辑和导出对两种来源开放；文案重写等额外模型调用另行明确触发。
