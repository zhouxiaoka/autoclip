## 新规则

| ID | 规则 | 依据 |
|---|---|---|
| **TA-1** | 标题或封面主句**以往事开头**（「当年……」「他曾经……」）→ −6，改写成结论句再评 | 往事类中位 0.71×（n=25），唯一明显拖后腿的特征 |
| **TA-2** | **名人 × 人人都面对的决定**（择业、伴侣、上学、听谁的意见、存钱）→ +8 | 全样本前 4 大爆款里有 3 条是这个结构（47×、27×、24×） |
| **TA-3** | 切身但**没有**名人/权威、反常识、事件中任何一个 → 切身分封顶 50% | 昌健胡说同号对照：长寿/数据安全 5–7 千 vs 工作/上学 12–18 万 |
| **TA-4** | **大家都听过的判断**（「AI 会取代很多工作」类）且没有新数字/新词 → −8（沿用并加重 R-S 共识惩罚） | 本号「一半工作」143，垫底 |
| **TA-5** | 选题大类**不直接加分**；大类只决定平台和目标：D→收藏（XHS 优先）、C/E→评论、A/B→点开 | 八个大类中位 0.83–1.23×，区间重叠 |
| **TA-6** | 推广、预告、问候、只有链接 → 不进候选 | H 类；志在四方问候帖 300 多 vs 金句帖 14 万 |
| **TA-7** | 雷达输出带**命中概率提示**而不是只给分：「同类特征历史命中率约 30%」，避免把规则当成保证 | Salganik 等 2006：爆款本身难预测 |

## 立即剪门槛（更新）

```
不是 H 类，且通过完整度和原话可核门禁
且 满足下面至少两条：
   挂靠事件 / 说话人对此题有权威 / 可执行方法 / 名人 × 人人都面对的决定
且 TA-1、TA-4 都没有触发
→ 立即剪
```
