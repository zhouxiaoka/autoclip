# 游戏买量素材：产品交付与质量标准

2026-09-21 更新。依据用户最新要求：输出质量对标游戏买量素材。本文件定义最终交付；[多模态检索设计](MULTIMODAL_HIGHLIGHTS_PLAN.md) 是其上游能力，不再单独以“找准高光并导出”作为产品完成标准。

首批方向由超休闲闯关扩展为用户提供的跑酷、合成与驾驶录屏；先完成跑酷样片，再验证另外两类。具体方案见[三条输入与制作流程](GAMEPLAY_TO_UA_WORKFLOW.md)。具体游戏、目标人群与投放渠道待定；已主动建立[效果案例库](GAME_AD_GOLDEN_CASES.md)，严格 Golden 的单片规模证据尚待补齐。尚未进行真实投放或成片验收。

## 1. 产品承诺

**从真实游戏素材中，制作让人看懂玩法、产生尝试欲望、可进入投放测试的视频创意。**

输入：一批录屏、玩法与卖点说明、目标人群/地区/渠道、品牌素材及可用音效；参考广告由产品研究主动查找，按[Golden 入库标准](GAME_AD_GOLDEN_CASES.md)核验，不要求用户先提供。

输出：一个完整广告概念的成片、2 个有明确测试假设的变体、可追溯编辑方案及质量检查结果。首轮只围绕一个概念变更开头或节奏，不随机排列成几十条。

早期提供可人工修改的半自动创作流程，以成片质量和节省的制作时间验收。后续用通过验收的样片固化自动化规则。

## 2. 买量质量分成三层验收

| 层级 | 验收内容 | 证明方式 |
| --- | --- | --- |
| L1 素材正确 | 事件真实、玩法可见、定位正确、剪辑连续 | 原片对照、事件标注与时间检查 |
| L2 创意与制作合格 | 开头吸引、目标清楚、过程有推进、结果有反馈、视听完成度合格 | 同赛道参考片拆解、人工成片评审、同素材人工版本对照 |
| L3 投放有效 | 有效观看、安装成本与安装后价值达到业务目标 | 相同或可比投放条件下的真实数据 |

首个版本必须做到 L2 的小范围人工验收。L3 必须经过实际投放，不能由 Seed/Jev 的分数、炫目的音效或一次主观好评代替。参考广告公开可见、播放多或运行时间长，也不能直接证明它的 ROI。

## 3. 成片质量检查表

以下为内部起始标准，不是平台强制规格。硬性问题先处理，再讨论综合分。

| 维度 | 要检查的问题 | 不通过的典型表现 |
| --- | --- | --- |
| 开头钩子 | 首屏有可识别的目标、障碍、选择或悬念吗？非玩家能理解为什么继续看吗？ | 先加载、先片头，精彩动作发生却看不懂缘由 |
| 玩法与卖点 | 观众能看懂“做什么、怎么做、会得到什么”吗？有一个主要卖点吗？ | 无关爽点堆积，只有结算，玩法信息不足 |
| 情绪推进 | 是否有挑战、行动、反馈；失败是否让人想尝试，成功是否有满足感？ | 一直同强度、重复奖励、铺垫与结果无关 |
| 剪辑连续性 | 起止保留关键因果；不同局次是否明确区分；变速后动作仍可读吗？ | 拼接不同关卡伪装同一局，反转没有依据，关键动作被截断 |
| 画面与文字 | 操作区、目标、HUD 是否清楚；字幕层级与安全区域是否适配具体版位？ | 竖屏裁掉危险来源，字幕盖住目标，压缩后文字不可读 |
| 声音与节奏 | 音效是否对应动作；原声、音乐、旁白是否清楚；是否突断或削波？ | 每个切点都加音效，音乐淹没游戏反馈，旁白解释重复信息 |
| 收尾与行动 | 是否有清楚的结果或有意设计的悬念；CTA 是否与画面卖点和实际入口一致？ | 最后一秒硬切、泛化号召、用不存在的玩法诱导尝试 |

首 2–3 秒的快速理解可作我们内部的钩子检查点，不能机械要求所有广告同一节奏。TikTok 的超休闲创意指南强调开头、游戏吸引点和结尾的组合，并建议测试不同创意；平台建议属于起点，不是通用成功公式。[官方创意指南](https://ads.tiktok.com/business/creativecenter/quicktok/online/tiktok-hyper-casual-game-creative-tips/pc/en)

硬性退回：黑帧/音画错误、字幕遮挡关键玩法、画面与文字冲突、事件因果误拼、素材不足仍编造玩法。模型可提出“补录什么”，不能把缺失镜头当作已有证据。

## 4. 模型与制作模块的职责

```text
游戏录屏 + 创意简报 + 参考标准
  → Seed：理解玩法、事件、镜头可用性与原片证据
  → 候选素材库：可作钩子 / 挑战 / 行动 / 反馈 / 收尾
  → 创意规划模型：提出完整概念，生成可追溯剪辑方案
  → Jev（可选）：对候选与方案做多项快速判断
  → 确定性渲染：剪辑、变速、重构画幅、文字、声音、尾卡
  → 成片复看 + 人工评审
  → 有假设的变体 → 人工发布与投放 → 反馈回流
```

Seed 先看懂发生了什么，还要识别镜头的创意角色。同一条失败镜头可能适合做开头，普通操作可能是解释玩法不可缺的中段；不能只按“最激烈”排序。

创意规划需要综合目标、受众、镜头组合与节奏，可先由同一 Seed 模型分阶段完成，不必再接第三家模型。它输出结构化编辑方案，包括原片及起止时间、镜头角色、速度、构图、字幕、声音、衔接与 CTA；由代码验证和渲染。

Jev 评估已有文字证据中的单项条件，例如钩子是否清楚、动作与结果是否相符、两个段落是否重复。它不能直接复看最终视频，也不能凭结构化分数证明广告有转化效果。片段分数相加不代表完整广告好看，必须评审完整序列。

现有发布导出只覆盖画幅、字幕、标题等部分能力，完整买量素材还缺创意编排、声音设计、镜头级参数和整片验收。这些要进入近期交付，不能将“增加一个导出预设”当作完成。

## 5. 首批只做三个可解释的创意结构

| 结构 | 需要哪些真实镜头 | 主要动机 | 容易出现的问题 |
| --- | --- | --- | --- |
| 差一点成功 | 明确目标 → 接近成功 → 关键失误/失败 | “我能做得更好” | 没有目标铺垫，失败显得随机 |
| 越来越爽 | 简单反馈 → 难度或奖励升级 → 高价值回报 | 成长、解压、获得感 | 同类奖励重复，节奏不推进 |
| 一次关键选择 | 可理解的选择 → 操作 → 明确后果 | 好奇、策略、挑战 | 选择与结果来自不同局，因果失真 |

MVP 只选素材最充足的一种结构完成；其余是候选，不同时实现。优先选最容易做出优秀样片的结构，而非预先强迫素材套模板。

示例：一条约 20 秒的“差一点成功”样片可以用危险选择作开头，接可读的操作与进展，再给真实失败反馈，最后邀请尝试。秒数和顺序由镜头决定；这是创意说明，不是已有素材的事实描述或固定 20 秒模板。

首批默认基于真实录屏重组制作，是否加入生成镜头、虚构情节或口播人物属于之后单独确定的创意范围。首版同时能输出补录单：缺什么画面、目标状态、需要保留的动作与长度。

## 6. 用参考片定义“对标”

对标优先选择效果和规模都有依据的具体视频。已建立[首批效果案例及 Golden 候选库](GAME_AD_GOLDEN_CASES.md)和[结构化记录](golden_cases/registry.json)：两条官方效果案例关联视频、一个规模化广告活动；当前没有单片证据完整的严格 Golden。活动安装量不能赋给其中任一视频。

完整播放并核验后，逐镜头标注开头信息、玩法解释、情绪推进、镜头长度、文字和音效密度、画面布局、结尾方式；未播放成功的媒体不填时间标注。借鉴结构和完成度，不复制对方具体素材。历史案例作为研究基础，持续补近期同赛道赢家和失败对照。

同游戏、同素材池、同创意简报，制作一个人工参考版本与一个系统版本，匿名并排评审。至少两位评审，其中一位有游戏买量制作或投放经验；若条件不足，明确记录仅为单人主观验收。

每个维度使用 1–5 分锚点：1 分妨碍理解，3 分能进入内部评审但需修改，5 分达到当前参考片完成度。初期要求无硬性缺陷，开头、玩法表达、节奏三项不能低于 3；不只看总平均分。

目标是让评审认为“可以进入小规模投放测试”，并记录需要人工修改的分钟数及修改原因。未经投放的片仍标记“待测试创意”，不称作高转化素材。

## 7. 变体与投放反馈

第一批做一个基础成片和两个变体，明确只改一个主要变量，例如同主体的三个开头。保存 `creative_id`、素材池、概念、钩子、编辑方案、模型/提示词版本、渲染版本、渠道与语言。

按渠道真实定义记录早期观看、完播、点击、安装和后续价值。CTR 变高但安装率、留存或 ROAS 变差时，不能判断为优胜创意。预算、受众、版位、地区、时间和归因窗口不同，结果不能直接比较；小样本只记方向与不确定性。

最初人工导入投放汇总即可，不急于接平台自动投放。先统一创意 ID 与归因口径，有稳定使用后再自动化数据回流。频繁测试与本地化可参考平台建议，但具体规格须在目标渠道确定后重新核验。[AppLovin 创意测试建议](https://support.applovin.com/en/growth/promoting-your-apps/track-and-optimize/scale-your-campaign)

本次没有创建广告、充值或消耗投放预算。

## 8. 修订后的交付顺序

1. **第一阶段：验收样片。** 选定游戏和渠道，依据已查证参考及证据缺口确定验收范围；用 Seed 找素材，人工参与编排，完成一条达到参考完成度的广告。第一周的模型原型只是中间成果。
2. **第二阶段：把样片流程产品化。** 把镜头角色、时间、文字、声音与渲染规则落为编辑方案；同一素材池可重现样片，并允许替换镜头和修改开头。
3. **第三阶段：变体与 Jev 对照。** 做基础片 + 两个变体，验证 Jev 是否减少筛选/评审时间，同时保持整片质量。
4. **第四阶段：小规模投放与扩场景。** 完成授权后的投放验证；先修当前游戏的质量短板，再扩第二类游戏。

仍按每周 5–10 小时估算：前 1–2 周争取 Seed 原型与首条人工参与的样片；第 3–4 周做可重复制作与变体；第 5–6 周做整片质量、Jev、复用与实际可取得的反馈。拿到游戏和素材、完成参考核验后再校准工时，不将 72 小时原型承诺等同于成熟买量系统。

产品成功指标相应调整为：每周通过人工创意验收的素材数、单条达到投放测试门槛的人工时间、素材复用率、变体测试速度，以及有足够数据后的投放结果。高光检索准确率仍是上游质量指标。
