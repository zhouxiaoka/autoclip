## 升级与回退演练方法（macOS非空受控夹具已完成）

1. 使用隔离账户或数据副本，先退出旧版及其后端/worker，确认无写入后复制完整应用配置目录、实际数据目录和外部原素材。数据库与项目目录必须来自同一次停机备份；包括存在的SQLite WAL/SHM，不能只拷一个活动中的数据库文件。记录路径与旧版安装包校验值，备份不提交仓库。
2. 记录旧项目数量、一个旧切片及合集、配置和隐私选择。安装候选后核对这些内容，再在副本中执行导入确认、编辑保存、导出与系统下载。保留输入、输出和版本记录；禁止在用户主工作区演练。
3. 模拟失败恢复：关闭/重开候选，运行中分析与导出应有明确失败/恢复入口，不能自动重跑付费模型；已有成功版本仍可下载。
4. 回退时先停止候选及后端，另行归档候选期间产生的数据与导出文件。恢复升级前的完整数据/配置副本，再用已核验的旧版启动。不要让旧版直接写入迁移后的数据库，也不要删除新生成内容。旧版不能显示Studio草稿不等于其文件已丢失，候选归档必须保留。
5. 再核对旧项目、播放、下载、设置与隐私选择。将每步结果和失败记录附于发布计划；未经演练不得声称可安全降级。

## 9月27日：macOS 优先验收范围

用户暂无 Windows 电脑，已明确先完成 macOS，Windows 保留待验收，不把构建通过视为原生安装/导入/保存通过。官方 v1.3.5 ARM64 包 SHA256 核验后，用其包内模型建立包含项目、切片、合集、源视频、测试字幕、设置和隐私选择的非空受控夹具；停机完整备份→候选升级与旧切片竖屏导出→另存候选新内容→恢复备份→旧版启动，三阶段全部通过。回退后原生界面可见原项目/切片/合集。当前候选 DMG 只读挂载、CRC、深度签名、隔离空目录原生启动和退出卸载通过。证据见 [macos-upgrade-validation-20260927.json](evidence/macos-upgrade-validation-20260927.json)。这是当前机器的受控数据演练，不是用户真实数据库迁移或第二台全新 Mac 的 Gatekeeper 验收。

此前数据库副本的7张表实际均为空，原报告已补充此限制，不再用它证明旧项目保留。六个真实候选已全部渲染为1080×1920含原声视频并完整解码；抽帧检查发现第三条保留约0.1秒原片白色转场，待创意边界进一步复核。见 [six-highlights-render-validation-20260927.json](evidence/six-highlights-render-validation-20260927.json)。单一跑酷样本及抽帧检查不代表多游戏、完整观感或买量质量验收。

### 原生真实模型端到端（同一候选包）

从原生文件导入恢复确认，手动选择视觉分析及高光/推广，保留自动参数；约146.65秒生成6段高光、3条推广草稿，随后从项目页导出并保存至系统下载目录。17.5秒成片包含原声，保存文件与导出任务SHA256一致，完整解码通过。不是注入历史分析结果的回放。证据见 [native-real-e2e-validation-20260927.json](evidence/native-real-e2e-validation-20260927.json)。

本次也暴露待修复项：由本地字幕推荐切到视觉分析后，推广的自动画幅仍沿用原画幅，实际输出1920×1080；需在确认时按制作目标重新匹配，同时保留用户显式画幅选择。六段时长8.5–30秒，短起跑片段仍需完整事件审阅。三个推广草稿是同一事件的不同文案，尚不构成多创意制作质量验收。macOS基础运行/升级/导入至保存已取得证据，不能把本报告写成最终发布或买量质量批准。
