## 候选范围

1. 无效旧封面配置不再挡住 AI 模型设置；保留原配置并允许修正，对应 #257 / #258。
2. GET 等安全请求保留重试预算，持续 500/503/超时最多重试两次；写请求不自动重试。
3. 自动出片失败保留受控错误码，并进入前端终态统计。
4. 旧 SQLite 被占用时，初始化的可选 journal 探测可推迟，不把整个连接当成失败。
5. 无效旧分析/视觉配置单独提示，保留其他有效连接；损坏的新设置文件允许在编辑器修正，显式保存时私下备份原文件。不截断密钥、不清空地址后把原密钥发往默认服务；运行时读取仍严格拒绝损坏文档。
6. SenseVoice 状态改为独立临时文件并在关闭句柄后原子替换，绕过残留只读临时文件；损坏的 status/ready JSON 可恢复。
7. 共用 YuNet 检测器的创建/推理加锁并复制结果，防止多个视频同时检测时互相覆盖输入、混入错误的人物位置。
8. 独立配置的旧 Gemini/Grok/GLM 封面服务保持原生生图协议和原地址，避免被迁为 OpenAI 协议；三项真实迁移边界回归在旧实现下失败。
9. Windows job 在新回归中发现独立临时文件仍不能保证两个并发替换成功（WinError 5）。状态读写再共享进程内锁，补充无 mock 的 8 线程/100 次读写回归；原操作锁仍负责跨进程安装/推理互斥。
10. SenseVoice 模型准备的 ready 文档也使用关闭后的独立临时文件和共享读写锁；残留只读 `ready.tmp` 不再阻断准备。
11. 自动流程在筛选阶段失败时同步结束 generation；渲染/按需准备的失败保留受控错误码，汇总区分单一和多类原因；成功重试清理旧码，partial 也记录失败部分。
12. 按需生成、重试、渲染和视觉分析遇到执行器拒绝派发时回到可重试失败状态，保留已有成片，不留在 preparing/running/queued；一条派发失败不阻断其他平台版本。
13. 损坏的配置不再被标记为已保存，首页恢复连接服务入口；三种损坏文档的回归均在原实现下失败。隔离浏览器验收确认修正后能发现模型、测试连接、保存与刷新；原始损坏文件按原字节备份，权限为 0600。
14. 原生候选包验收复现一键出片启动时误跳旧确认页：自动导入从创建时就不再标为待确认，旧自动项目也保持在进度页；手工导入仍要求确认。暂停筛选 worker 的真实 API/数据库回归在原实现下失败，修复后通过。
15. 真实 qwen-plus 成片的本地输入没有节目出处，文案却填出节目名或空出处括号。提示明确未知出处不猜测，且本机拦下没有依据的出处描述，保留标题和正常描述；四项实际输出条件在旧实现下失败。该规则不保证所有模型事实正确，仍需逐片内容验收。
16. 实际 macOS 候选包准备 SenseVoice 时，editdistance 在包内 Python 3.13 上回退为源码编译并因 SDK 链接失败；源码 CI 自带编译工具，未暴露终端安装条件。桌面构建用实际 portable Python 提前构建并验证该 wheel，随 backend 打包；终端安装禁止该依赖源码编译。两个桌面构建新增实际安装包内 SenseVoice 准备、模型下载和离线转写检查。以新提交/安装包结果为准，旧绿灯不能放行。

17. 原生自动筛选短暂显示手动确认说明，失败后的上方状态还声称 AI 正在制作。自动流程不再要求确认，失败显示终态；三个真实组件渲染回归保留手动说明，其中两个在原实现失败。

18. 新的原生 qwen-plus 验收文案给本地字幕补入没有出现的 Meta / 扎克伯格标签。未知出处的本地素材只保留字幕中出现的原词，不根据参考标题推测身份；先过滤再应用平台数量上限，英文词按完整词匹配。三个真实输出条件在旧实现下失败，修复后发布文案的 17 项回归通过。已知出处保留原平台话题规则；该规则仍不保证标题和描述的所有模型事实正确。

19. 普通渲染重试只在锁外检查 failed，另一请求已领取或完成后仍可能被旧请求改回 queued 并清掉任务关联。与准备重试一样，在同一次锁内修改中重新核验 failed，保留另一请求的任务和终态。真实 JSON 存储的可控交错回归覆盖 queued/running/completed 三种情况，原实现三项均失败，修复后相邻 25 项回归通过。
