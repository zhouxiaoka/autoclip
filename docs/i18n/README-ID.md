# AutoClip

### Satu tautan. Satu klik.

Sumber terbuka (open source), dengan pemotongan dan rendering di komputer Anda. Tempel tautan, pilih platform, dan dapatkan <b>video, sampul, dan teks postingan</b>,<br>
untuk Douyin, Xiaohongshu, TikTok, Reels, YouTube Shorts, Bilibili, atau YouTube.<br>
Aplikasi ini gratis; model cloud dikenai biaya sesuai pemakaian. Buka editor kapan pun Anda ingin menyesuaikannya.

## Apa fungsinya

### Tempel tautan, dapatkan klip

Pilih platform untuk menghasilkan video sesuai aturan bingkai dan durasinya. Setiap platform secara otomatis me-render hingga 10 klip terbaik yang memenuhi syarat; sisanya menjadi alternatif sesuai permintaan (on-demand). Setiap klip mencakup sampul, judul, deskripsi, tagar, dan paket publikasi ZIP.

### Pengemasan sudah siap pakai

Douyin / Xiaohongshu secara default menggunakan gaya wawancara; TikTok / Reels / Shorts secara default menggunakan gaya podcast layar penuh. Anda dapat memilih salah satu tata letak vertikal tanpa mengubah bahasa takarir/teks platform tersebut. Bilibili / YouTube menggunakan format lanskap. Pembingkaian mengikuti pembicara dan mempertahankan bingkai penuh saat tidak ada orang yang terdeteksi. Outro merek aktif secara default dan dapat dinonaktifkan di Pengaturan; teks postingan yang disalin tidak menyertakan kredit AutoClip.

### Tetap di komputer Anda

Pemotongan, pembingkaian, dan rendering berjalan secara lokal. Pilih model analisis Anda dan gunakan takarir kreator, Whisper / SenseVoice lokal, atau transkripsi cloud yang telah dikonfigurasi. CLI / MCP berbagi alur kerja output cepat (quick-output pipeline) yang sama dengan versi desktop.

## Pilih model dan alur data Anda

Pemotongan dan rendering berjalan di komputer Anda. Analisis cloud mengirimkan takarir dan teks postingan yang relevan; pemahaman visual atau pembuatan gambar referensi mengirimkan bingkai sampel yang diperlukan, dan ASR cloud mengirimkan audio. Analisis dan transkripsi lokal tidak memerlukan API cloud terkait. Klip yang sudah jadi diunggah ke platform terhubung saat Anda memilih untuk memublikasikan. Analitik dan laporan galat dapat dinonaktifkan di Pengaturan. Lihat [privasi](../PRIVACY.en.md).

## Mulai cepat

| Anda ingin | Gunakan | Yang dibutuhkan |
| --- | --- | --- |
| Membuat klip di komputer ini | **Desktop** | macOS Apple Silicon atau Windows x64 |
| Self-host / Linux | **Docker** | Docker dan Compose v2 |
| Batch / agen | **CLI / MCP** | Python 3.10+ (disarankan 3.11) dan FFmpeg |

### Desktop

1. **Instal.** Unduh dari [Releases](https://github.com/zhouxiaoka/autoclip/releases/latest). macOS Apple Silicon: `.dmg`. Windows 10 / 11 x64: `-setup.exe`. Python dan FFmpeg sudah disertakan di dalam paket. Pada macOS 15 ke atas, klik dua kali sekali; jika terblokir, buka System Settings → Privacy & Security → Open Anyway ([catatan Apple](https://developer.apple.com/news/?id=saqachfa)). Pada macOS yang lebih lama, klik kanan aplikasi lalu pilih Open. Jika Windows SmartScreen muncul, pilih More info → Run anyway.
2. **Konfigurasi model.** Pilih penyedia dan masukkan kunci API-nya, pilih model analisis yang tersedia, uji koneksi, lalu simpan. Untuk model lokal, jalankan Ollama / LM Studio dan muat model terlebih dahulu.
3. **Lihat contoh, lalu gunakan video Anda sendiri.** Saat layar utama belum memiliki proyek, klik “用示例项目看看效果” (Lihat proyek contoh). Ini tidak memerlukan kunci API; contohnya sudah ada di dalam pemasang. Setelah itu, gunakan wawancara atau podcast Anda sendiri dan pilih tata letak vertikal. Jika sumber tidak memiliki takarir, atau Whisper lokal gagal terinstal atau terlalu lambat, buka Settings → Default models → “Speech to subtitles” lalu alihkan ke transkripsi cloud Bailian (`qwen-audio-3.1-asr-flash`, sekitar 0,1 yuan per jam audio; biaya sebenarnya sesuai tagihan Alibaba Cloud). Audio akan diunggah ke cloud. Jika impor terblokir, klik “Use cloud transcription instead”. Instalasi lokal pertama mengunduh sekitar 220 MB, sekitar 15 menit pada jaringan yang lambat.
4. **Tinjau dan unduh.** Periksa takarir, pembingkaian, dan kelengkapan konten, lalu simpan paket publikasi atau hubungkan akun untuk memublikasikan. Hasilkan alternatif sesuai permintaan saat Anda membutuhkan lebih banyak klip.

Tidak tersedia build desktop untuk Intel Mac. Intel Mac dan Linux menggunakan Docker atau CLI. Pemasang desktop saat ini belum ditandatangani (penandatanganan kode / notarization dilacak di [#119](https://github.com/zhouxiaoka/autoclip/issues/119)), sehingga Windows SmartScreen, heuristik antivirus, atau macOS Gatekeeper dapat menampilkan peringatan pada build baru; setiap paket dibangun secara publik di GitHub Actions (`Desktop Build`) dan disertai `build-provenance.json` agar Anda dapat memverifikasi hash SHA-256 secara persis sebelum dijalankan (atau gunakan Docker / CLI / kode sumber). Lihat [panduan instalasi](../USER_INSTALLATION_GUIDE.en.md) dan [Rilis terbaru](https://github.com/zhouxiaoka/autoclip/releases/latest).

[Panduan instalasi lengkap](../USER_INSTALLATION_GUIDE.en.md) · [Pemecahan masalah](../FAQ.en.md)

**CLI / MCP (Claude Code, Codex, OpenCode & skrip)**

```bash
uvx autoclip-mcp
npx skills add zhouxiaoka/autoclip

autoclip --version
autoclip produce talk.mp4 --srt talk.srt --platform tiktok --portrait-style podcast --json
autoclip outputs PROJECT_ID --export-kits
```

```bash
# Or install from source
python -m pip install --no-deps .
```

To build a local MCPB bundle without publishing, run `python scripts/pack_mcpb.py` (never run `smithery mcp publish` automatically).

</details>

## FAQ

<details>
<summary>Apakah gratis? Apakah saya perlu kunci API?</summary>

Aplikasi ini gratis dan berlisensi MIT. Analisis cloud, transkripsi, dan gambar AI menggunakan kredensial Anda dan tarif penyedia layanan; desain sampul otomatis tidak menggunakan pembuatan gambar berbayar secara default. Ollama / LM Studio tidak memerlukan kunci cloud tetapi membutuhkan perangkat keras yang memadai. Publikasi langsung memerlukan akun Bilibili atau [Upload-Post](https://www.upload-post.com) milik Anda sendiri.

</details>

<details>
<summary>Apakah video saya diunggah?</summary>

Pemotongan dan rendering berjalan di komputer Anda. Analisis cloud mengirimkan takarir dan teks postingan yang relevan; pemahaman visual atau pembuatan gambar referensi mengirimkan bingkai sampel yang diperlukan, dan ASR cloud mengirimkan audio. Analisis dan transkripsi lokal tidak memerlukan API cloud terkait. Klip yang sudah jadi diunggah ke platform terhubung saat Anda memilih untuk memublikasikan. Analitik dan laporan galat dapat dinonaktifkan di Pengaturan. Lihat [privasi](../PRIVACY.en.md).

</details>

<details>
<summary>Video seperti apa yang paling cocok?</summary>

Wawancara, podcast, kursus, dan rekaman orang berbicara (talking-head) adalah skenario yang paling teruji. Takarir dari kreator paling cepat diproses; jika tidak ada, gunakan transkripsi lokal atau cloud. Untuk rekaman gameplay atau video dengan sedikit dialog, aktifkan pemahaman visual dengan model yang mendukung gambar dan tinjau momen yang dipilih.

</details>

<details>
<summary>Mengapa tidak ada klip yang dihasilkan?</summary>

Periksa tahap yang gagal: takarir/transkripsi, koneksi model, FFmpeg, ruang disk, dan kelayakan platform. YouTube format panjang memerlukan klip utuh minimal 180 detik; gunakan Shorts atau Bilibili untuk rekaman yang lebih pendek. Jika masih gagal, sertakan versi dari `autoclip --version`, sistem operasi, durasi sumber, model, dan log yang telah disanitasi di [masalah yang diketahui](https://github.com/zhouxiaoka/autoclip/issues/96).

</details>
