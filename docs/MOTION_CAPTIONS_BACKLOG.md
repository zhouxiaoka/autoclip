# 动效字幕：后续待办

2026-09-22用户明确要求“成片包装先收尾，动效字幕往后排期”。卡拉 OK、逐词高亮、逐字扫色不进入本轮包装交付，也不作为1.4 RC的新增依赖。具体版本和日期另排，当前不继续开发。

已有基础保留：本地 Whisper 请求真实词时间，保存带SRT哈希的旁路文件；字幕解析区分ASR与估算时间，编辑/翻译会使旧对齐失效。当前没有面向用户的动效开关。

恢复开发时按顺序处理：

1. 将源词时间按镜头裁切与重排映射到成片时间，保留停顿并处理跨切点词。
2. 只对可用ASR或人工确认时间开放效果；普通SRT提供对齐入口。目标语言语音需要独立对齐，不能沿用源语言词时间。
3. 第一批实现逐词点亮和从左到右扫色，独立于标题模板设置，保持预览与导出一致。
4. 用真实中英文口播评估延迟、对齐精度、性能和失败回退，再确定后续弹跳等复杂效果。

验收需覆盖重排/截断、长停顿、无语音、改字、翻译、原声关闭以及历史项目；不能把平均分配的词时间标为精确对齐。
