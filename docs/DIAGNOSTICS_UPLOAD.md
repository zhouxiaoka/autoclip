# 失败诊断上传

状态：生产 Worker 已上线，但那次部署早于「链接只传地址」的桌面规则，生产是否已更新仍待核对。桌面端内置地址是 `https://autoclip-diagnostics-api.autoclip-val-3f71ee83.workers.dev`。没有保存过选择时，失败诊断和压缩短片段按默认上传，完整原片为关闭。第一次任务失败时，底部会出现一条几秒后自己消失的说明，不需要点确认，也不停止上传。这条说明记在本机偏好里，不是诊断开关。已经保存的关闭保持关闭。

## 用户能做什么

- 没有 `diagnostics/consent.json` 时，总开关和短片段按打开处理，完整原片按关闭处理。这不是以前的单独同意。
- 不在导入时弹说明，也不在启动时放卡片，也不为了提示跳进详情。项目在当前这一屏从进行中变成失败时（首页列表，或人已经停着的制作页）底部出现一条轻提示，大约 7 秒后消失；鼠标停在上面或焦点在里面时先暂停，最长大约 20 秒仍会收起。打开应用时已经失败的项目不算这次，不会补提示。提示不挡操作，也不改开关。打开收集时只说「我们会收集本次错误信息，帮助改善体验，可在设置中关闭。」不提视频。总开关关掉时，写明这次不会自动发送。提示里的「设置」打开现有的「设置 → 应用」。短片段、链接、完整原片和 14 天删除仍写在设置里。看过一次就记在本机偏好 `autoclip.diagnostics.failure_hint.v1`，重启后不再出现。关掉提示或等它消失都不写成同意。更早已经保存的关闭不会被重新打开。用户后来自己打开总开关时，只发送打开之后的新失败。
- 已经写成关闭的选择会原样保留，不会因为这次默认打开而被重新打开。读不出来的同意文件也不会被当成新的打开。
- 后台在片段打开且完整原片关闭时，上传重新编码的短片段，不回退成完整原片，也不发送字幕正文。用户打开完整原片后，原片按原文件上传，不再转码。关掉总开关会取消尚未完成的上传。只关掉某一类素材时，取消带有该类素材的队列，不取消只有脱敏清单的项目。
- 用户用链接导入时，诊断只带上清洗后的来源链接，不上传下载下来的视频、短片段或完整原片，也不会为了诊断去转码。本地文件仍按上面的短片段规则。看不出是链接还是本地文件时，不自动上传素材。诊断服务不会去打开或请求这个链接。
- 失败卡上的「提交诊断」仍会先列出将要发送的字段，素材复选框默认不勾选。
- 关掉设置会停掉新的上传，取消队列，并尽量中止正在进行的上传。撤销之后不会再申请新的上传许可。
- 确认删除或取消之后，会删掉该诊断自己的 `excerpts/<id>`。远端删除已经确认、或从未需要远端清理时，一并删掉能力令牌和恢复凭据。远端删除还要重试时，这两份凭据留着。项目里的原片不会删。
- 已上传的诊断由服务端在 14 天后自动删除。用户不必自己删除。
- 用户选择保存到本机时，不走上传。网络失败时，同一次提交可以改存本机。本机导出不是主路径。

## 不会发送的东西

API 密钥、Authorization、密码、cookie、个人路径、项目名、转写正文、原始日志目录、`settings.json`、数据库。来源链接只保留清洗后的公开地址，可以带普通视频编号这类查询参数；密钥、签名、本地路径和账号信息不会发出去。日志只保留能通过行格式和脱敏的短句。

素材只来自该项目的 `raw/input.*` 和已有 `input.srt`。符号链接和逃出项目目录的路径会被拒绝。

## 和服务端的关系

已创建的资源：

- Worker `autoclip-diagnostics-api`：`https://autoclip-diagnostics-api.autoclip-val-3f71ee83.workers.dev`
- 私有桶 `autoclip-diagnostics`，绑定 `DIAGNOSTICS_BUCKET`
- D1 `autoclip-diagnostics-meta`，id `91ac62f9-8b47-4f88-af93-08c2706caace`，绑定 `DIAGNOSTICS_DB`

不使用现有的 `autoclip-media` 桶。模板和限制说明在 `services/diagnostics-api/README.md`。

桌面端地址优先级：环境变量 `AUTOCLIP_DIAGNOSTICS_ENDPOINT`，然后是数据目录里的 `diagnostics/endpoint.json`，最后是上面的内置地址。空的环境变量或空的文件值不会关掉内置地址。

已部署的上限：清单 256KB，字幕 2MB，片段 200MB，完整原片 2GB，已落地 4GiB，在途 2GiB，保留 14 天，未完成的 multipart 1 天后中止。账号免费层的 10GB·月不是硬性花费上限。
