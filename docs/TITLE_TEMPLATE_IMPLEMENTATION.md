# 文字模板：产品实现与验证

2026-09-22，独立分支 `codex/visual-game-ads`。设计方向图由 imagegen 生成，只用于风格探索；以下三款已经有真实产品实现和 MP4 输出。

## 实现选择

使用 **内置字体 → Pillow 透明图层 → FFmpeg 合成**。标题作为可配置图形，不调用生成模型绘字，也不要求用户启动 HyperFrames Studio。已有视频裁切、字幕、声音、后台任务继续由原渲染链路承担。

选择这条路径的原因：前三款的核心是字体轮廓、描边/阴影、色块和倾斜底板，静态高质量图层配短入场运动即可实现；可用当前桌面 Python/FFmpeg 运行时，不增加 Chromium 或外部 Studio 依赖。复杂逐字动效、真实动态磨砂、像素字体体系仍留待后续能力验证，不能用当前实现宣称六款全部完成。

## 已落地模板

| 标识 | 名称 | 图形 | 入场 |
| --- | --- | --- | --- |
| comic | 漫画冲击 | 窄体重字、深色描边和偏移厚阴影、轻微倾斜 | 短距离上移 |
| neon | 荧光挑战 | 白色主句、末行深色字与荧光色块 | 短距离上移 |

新推广草稿和“应用竖屏推荐”默认 comic；plain / impact / card 三款旧样式继续沿用，不重写历史草稿。新样式支持强调色、字号倍率（0.75–1.2）、纵向位置、动效开关。首帧文字可见；动效约 0.18 秒，开头文字仍只出现在首镜头最多 4 秒。

## 一致性与保存

- `title_art.py` 使用真实字体字宽换行、测量边界，保留用户手动换行；英文按词、中文按字符处理。最多三行，长文案缩字号，超过下限明确报错。强调当前是末行，不是模型自动识别关键词。
- `POST /studio/{project_id}/title-preview` 按输出分辨率返回透明 PNG，不保存草稿、不调用模型。编辑页以同一图层叠在原片上，250 ms 防抖，取消过时请求并释放 Blob URL。
- 渲染时同一个函数生成 PNG，再由 FFmpeg 叠加和移动。预览显示静态布局；翻译与动效在实际渲染预览中验收。翻译后的文案会重新排版。
- 缩略图也由同一个函数生成；`GET /studio/title-presets/{style}/thumbnail` 提供缓存，未知模板返回 422。
- `title_style`、`title_template_version=1`、`title_accent`、`title_scale`、`title_y`、`title_motion` 进入草稿和不可变导出快照。后续升级视觉规则须增加版本实现，不能悄悄改变已冻结的 v1。
- 最大图层 1600 万像素；几何边界留白会限制过大/过低的标题，避免文字被画布截断。这不是 HUD 检测，关键玩法区域仍需要复核。

## 字体与打包

内置 Barlow Condensed Black / Black Italic 和 Noto Sans SC 可变字体（绘字使用 900 字重），来源为 [Google Fonts 官方仓库](https://github.com/google/fonts)。字体原始 OFL 许可与版权随文件分发，固定提交、原始 URL 和 SHA-256 记录在 `backend/assets/fonts/manifest.json`。其中 [Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed) 用于拉丁文，[Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 用于中日文等字符；当前采用同一 CJK 字形体系，日文字形偏好仍需视觉验收。

字体资源约 18 MB，避免依赖用户系统字体或运行时下载。Pillow 固定为本机验证的 11.3.0；桌面复制脚本已覆盖 backend/assets，wheel package-data 显式包含字体、许可和 manifest。实际 wheel 构建成功并检查了六个资源条目及字体 SHA-256；这不替代 Windows/macOS 安装包测试。

## 本轮证据

- 三款各生成 10.02 秒、1080×1920、30 fps H.264/AAC 游戏样片，使用相同的 8–14 秒、16–20 秒源区间；六秒并排对比见本任务 `title-template-review/comparison.mp4`。
- 将三款预览 PNG 与真实 FFmpeg 输出帧在标题区域做像素差检查（关闭动效，允许 H.264 色彩转换误差），均通过。
- 验证中文、日文、特殊字符、显式换行、过长文字拒绝、颜色校验、预览不修改草稿/不调用模型、模板持久化和非法缩略图。
- 浏览器选择荧光挑战、再切换竞技斜切；字号 0.9 / 位置 0.16 保存为 V6，刷新后保留，实际渲染预览成功；三个真实缩略图加载成功。
- 后端 40 项、前端 12 项回归；类型、Lint 和生产构建验证结果记录在发布清单。

## 2026-09-22：对照设计图的加强版 v2

用户反馈首次实现相较设计图缺少力度。本轮对照原六款设计图，先实现其中四款：漫画冲击、荧光挑战、竞技斜切的加强版，以及新增极简大字；像素街机与动态磨砂没有在本轮假充完成。

- 漫画冲击：扩大字块、末行强调、加厚墨线与右下硬阴影、6° 倾斜。
- 荧光挑战：白色上句、宽荧光底板与黑色末行、短标记下划线、3° 倾斜。
- 竞技斜切：两层宽斜切深蓝底板、蓝色侧边、重斜体与荧光末行、5° 倾斜。
- 极简大字：奶白直立大字、左对齐、紧行距、朱红基线色条，无整块底板。

`title_art_v2.py` 实现新版绘字。`title_art.artwork(..., version=...)` 负责显式分派；原版实现冻结为 `_artwork_v1`。v2 字块限制在画布 90% 宽、26% 高范围，默认比首版靠上，仍需逐素材复核 HUD 与角色遮挡。英文和中文使用现有已打包字体，未增加字体下载与运行时依赖，也未增加外部 Studio 依赖。

缺省版本仍为 1，兼容旧草稿；新推广草稿、明确选择模板或应用竖屏推荐时使用版本 2。编辑器增加原版/加强版切换；极简大字仅支持 v2。预览请求签名包含版本，缩略图地址带 `?v=2`，导出使用草稿快照里的版本，避免预览与导出各用一版。

本轮证据：后端 53 项、前端 12 项检查通过，类型、Lint 和生产构建通过（保留已有大包提示）；新增四款 v2 的 PNG/真实导出像素一致性、中英日横竖屏边界、版本保存/拒绝未知版本与带版本缩略图检查。三款 v1 的中英文共六组像素与上一提交完全一致。

使用相同 8–14 秒、16–20 秒跑酷区间输出四条 v2 与三条 v1 对比，全部 1080×1920、10 秒。另有四款中文静帧；不把中文静帧描述为中文成片验收。审阅页支持逐款选择、原版/加强版视频切换、中文静帧和单独下载。复现命令：

```sh

```

源片需要覆盖到 20 秒。脚本使用隔离临时项目、不调用模型，输出 `evidence.json` 记录草稿参数与导出结果；`--reference` 可省略。当前任务产物为 `title-v2-review/index.html` 与 `contact.jpg`。用户逐款复看尚未完成，不能代填通过。


## 2026-09-22：光泽版 v3 与六款完整预设

根据用户对字面光泽的反馈，v3 在前四款几何结构上增加分段反光渐变、顶部/左侧亮边与右下暗边；漫画与竞技款较明显，极简与磨砂保持较轻的处理。这里的光泽是固定材质层次，不宣称动态扫光。v1/v2 的绘制实现保留；14 组原有中英文像素与上一提交一致。新推广稿与用户重新选择模板使用 v3，既存草稿不迁移。前四款可以在支持的历史版本间切换。

新增两款：

- **像素街机**：拉丁文字内置 [Press Start 2P](https://github.com/google/fonts/tree/main/ofl/pressstart2p)，在原生 8px 网格绘字，以整数倍率和最近邻放大；奶油色字面、莓红阶梯阴影、像素角框。中日文用 Noto Sans SC 的 20px 二值网格化回退，明确不是同一套原生 CJK 点阵字体。字体与 OFL 许可固定到现有 Google Fonts 提交，并更新 SHA-256 manifest；新增约 123 KB。像素款保持静止，避免平滑位移破坏像素网格。
- **磨砂字幕卡**：Noto 700、半透明炭灰卡、细高光边和青色侧条。`frosted_layers` 同时生成文字/材质图层与圆角区域遮罩；FFmpeg 对当帧背景做 Gaussian blur，再按遮罩合成。卡片外保持清晰，文字在模糊上层；标题与背景处理在 4 秒一起消失。不是单纯的半透明色块。固定位置让两层始终对齐，编辑器不展示该款的位移动效开关。

编辑器用同一遮罩加 CSS backdrop-filter 预览，模糊量按容器宽度缩放；浏览器与 FFmpeg 的模糊算法可能有细微差异，以实际导出为准。`title-preview?layer=backdrop` 仅接受 v3 磨砂模板，仍不调用模型、不保存草稿。渲染使用 [FFmpeg gblur / maskedmerge](https://ffmpeg.org/ffmpeg-filters.html#maskedmerge)，将原片和遮罩统一为 30 fps 与相同时间基，并在 RGB 三通道合成；首轮真实样片曾发现遮罩 25 fps 导致运动偏差及 YUV 中性色度遮罩导致卡片外颜色混合，均已修复并增加回归，不能用静态帧验证替代时间同步验证。

回归包含六款 v3 的 PNG/成片静态一致性、中英日横竖屏、版本持久化与拒绝错误版本、像素离散色板、磨砂遮罩接口、动态背景变色、卡片内外范围、4 秒消失边界、运动帧同步。字体 wheel 构建通过，七个字体/许可文件全部匹配 manifest。前端测试、类型、Lint 和构建通过；桌面安装包仍待发布回归。

审阅产物更新为 `title-v3-review`：六条 10 秒英文视频、像素/磨砂两条中文视频、六款中文静帧及四条上一轮 v2 对照。`scripts/render_title_review.py` 支持 `--baseline-dir` 复用上一轮对照（明确传入目录），默认会重新渲染对照；源区间仍为 8–14、16–20 秒。审阅页有六款切换、平色对照、中文静帧与新增两款中文视频。待用户逐款复看，不自动认定视觉定稿或买量质量验收。

v4 仅支持 `comic`，其余六款中的五款继续使用 v3。新漫画草稿/手动选择漫画使用 v4，已有草稿保留原版本；编辑器提供“设计校准版 / 光泽版 / 加强版 / 原版”。缩略图、预览与导出仍共用字层代码。

### 卡拉 OK 实施分期

已完成：本地 faster-whisper 使用 `word_timestamps=True`；SRT 旁保存 `*.words.json`，包含原句/词时间、语言、来源、schema 版本及 SRT 内容哈希。字幕处理器优先消费通过校验的 ASR 时间，保留词间停顿和标点，标记 `timingSource=asr`；老 SRT 的编辑兼容数据明确标记 `estimated`。非有限、越界、重叠、缺词、损坏、未来版本或 SRT 被修改时不提供精确词级时间。写入旁路数据失败保留普通 SRT；既存 SRT 不自动重新识别。

下一步：将词时间按草稿镜头裁切/重排映射到成片时间；只对 `asr` 或用户确认的手动对齐数据开放逐词高亮，普通 SRT 提示先对齐。先用 ASS/FFmpeg 实现逐词点亮和从左到右扫色，再接逐词弹跳等图层动效。用户界面把“文字外观”和“字幕动效”拆为独立选项。翻译后的字幕需要对齐目标语言语音或手动时间，不能继承原语言词时间。本轮没有暴露卡拉 OK 成片开关。

验证边界：词时间采集/读取使用可控 Whisper 输出做集成回归，没有下载或运行实际 ASR 模型；真实口播的对齐质量与新增计算耗时仍需样本验证。SRT 单独复制/导出不会携带旁路文件，跨项目导入精确词时间尚未实现。不要将本轮基础数据能力描述为已经完成动效字幕。

### 漫画 v5 可选强化

保留 v4 的默认行为，编辑器样式版本新增“冲击加强版”v5。v5 使用同一 Anton/Noto 字体基础，加粗字面、强化末行高度（两行时末行1.16、首行0.96）、缩短行距、整体倾斜10°并扩大爆点；自动生成和点击漫画预设仍选 v4。`comic_art.artwork(..., punch=True)` 仅由模板版本5调用；v4默认参数输出不变。
