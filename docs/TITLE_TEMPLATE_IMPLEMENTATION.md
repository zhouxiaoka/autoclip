## 渲染与一致性

使用内置字体 → Pillow 字层 → FFmpeg合成；用户不需要启动 HyperFrames Studio。`title_art.py` 按版本分派，`title_art_v6.py` 实现五款校准和漫画委托。任何后续视觉变化必须明确增加版本，不能修改已保存版本的含义。

- 选择卡片使用设计图裁出的本地 WebP，360×240；来源哈希和裁切框在 `frontend/src/assets/title-presets/manifest.json`。卡片明确标注为设计参考。
- `POST /studio/{project_id}/title-preview` 用真实文案返回PNG；不保存、不调用模型。前端防抖、取消过时请求并释放 Blob URL。
- 导出使用相同字层与草稿快照。构图预览是静态布局；入场、翻译、字幕时序以实际渲染视频为准。
- 磨砂的字层和背景遮罩来自同一个函数，预览使用 CSS backdrop-filter，导出使用 FFmpeg RGB maskedmerge。两种模糊实现会有细微观感差异。
- 参数进入草稿和不可变导出快照；前端 `titlePresets.ts` 集中维护模板清单、合法版本和设计缩略图。
- 缺字幕/缺音轨保留可导出的结果并显示具体提示；失败任务可重试，旧成片保留。

最大字层1600万像素。排版保留显式换行，最多三行，过长会缩字号或明确报错。英文按词、中文按字符换行；末行强调由排版规则决定，不宣称自动理解关键词。安全边距不是游戏HUD识别，仍需按素材检查遮挡。

## 字体与打包

内置 Anton、Barlow Condensed Black/Black Italic、Noto Sans SC、Press Start 2P 及各自OFL许可；固定来源和9份字体/许可资源哈希记录在 `backend/assets/fonts/manifest.json`。不依赖用户下载字体。拉丁文主要使用Anton；中日文使用Noto回退，日文字形偏好尚待更多真实样本确认。

Python wheel 包含字体、许可、manifest与渲染模块；前端构建打包六张设计缩略图。桌面安装包路径、Windows/macOS运行验证仍归1.4发布集成验收，不因wheel构建成功而标记通过。

## 复现样片

```sh
python scripts/render_title_six.py --source <gameplay.mp4> --reference <六宫格设计图> --baseline <v3目录> --comic-baseline <v5目录> --output <审阅目录>
```

脚本用隔离临时项目，不调用模型。支持在完整审阅目录存在后用 `--styles arena` 等参数单款重出并保留其他证据。历史对照目录是本任务的既存产物，不能在没有它们时声称完整复现通过。
