# 文字模板：产品实现与验证

2026-09-22，独立分支 `codex/visual-game-ads`。设计方向图由 imagegen 生成，只用于风格探索；以下三款已经有真实产品实现和 MP4 输出。

## 实现选择

使用 **内置字体 → Pillow 透明图层 → FFmpeg 合成**。标题作为可配置图形，不调用生成模型绘字，也不要求用户启动 HyperFrames Studio。已有视频裁切、字幕、声音、后台任务继续由原渲染链路承担。

选择这条路径的原因：前三款的核心是字体轮廓、描边/阴影、色块和倾斜底板，静态高质量图层配短入场运动即可实现；可用当前桌面 Python/FFmpeg 运行时，不增加 Chromium 或外部 Studio 依赖。复杂逐字动效、真实动态磨砂、像素字体体系仍留待后续能力验证，不能用当前实现宣称六款全部完成。

| 标识 | 名称 | 图形 | 入场 |

| comic | 漫画冲击 | 窄体重字、深色描边和偏移厚阴影、轻微倾斜 | 短距离上移 |
| neon | 荧光挑战 | 白色主句、末行深色字与荧光色块 | 短距离上移 |

新推广草稿和“应用竖屏推荐”默认 comic；plain / impact / card 三款旧样式继续沿用，不重写历史草稿。新样式支持强调色、字号倍率（0.75–1.2）、纵向位置、动效开关。首帧文字可见；动效约 0.18 秒，开头文字仍只出现在首镜头最多 4 秒。

## 一致性与保存

- `title_art.py` 使用真实字体字宽换行、测量边界，保留用户手动换行；英文按词、中文按字符处理。最多三行，长文案缩字号，超过下限明确报错。强调当前是末行，不是模型自动识别关键词。
- `POST /studio/{project_id}/title-preview` 按输出分辨率返回透明 PNG，不保存草稿、不调用模型。编辑页以同一图层叠在原片上，250 ms 防抖，取消过时请求并释放 Blob URL。
- 渲染时同一个函数生成 PNG，再由 FFmpeg 叠加和移动。预览显示静态布局；翻译与动效在实际渲染预览中验收。翻译后的文案会重新排版。
- 缩略图也由同一个函数生成；`GET /studio/title-presets/{style}/thumbnail` 提供缓存，未知模板返回 422。
- `title_style`、`title_template_version=1`、`title_accent`、`title_scale`、`title_y`、`title_motion` 进入草稿和不可变导出快照。后续升级视觉规则须增加版本实现，不能悄悄改变已冻结的 v1。
- 最大图层 1600 万像素；几何边界留白会限制过大/过低的标题，避免文字被画布截断。这不是 HUD 检测，关键玩法区域仍需要复核。

## 字体与打包

内置 Barlow Condensed Black / Black Italic 和 Noto Sans SC 可变字体（绘字使用 900 字重），来源为 [Google Fonts 官方仓库](https://github.com/google/fonts)。字体原始 OFL 许可与版权随文件分发，固定提交、原始 URL 和 SHA-256 记录在 `backend/assets/fonts/manifest.json`。其中 [Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed) 用于拉丁文，[Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 用于中日文等字符；当前采用同一 CJK 字形体系，日文字形偏好仍需视觉验收。

字体资源约 18 MB，避免依赖用户系统字体或运行时下载。Pillow 固定为本机验证的 11.3.0；桌面复制脚本已覆盖 backend/assets，wheel package-data 显式包含字体、许可和 manifest。实际 wheel 构建成功并检查了六个资源条目及字体 SHA-256；这不替代 Windows/macOS 安装包测试。

## 本轮证据

- 三款各生成 10.02 秒、1080×1920、30 fps H.264/AAC 游戏样片，使用相同的 8–14 秒、16–20 秒源区间；六秒并排对比见本任务 `title-template-review/comparison.mp4`。
- 将三款预览 PNG 与真实 FFmpeg 输出帧在标题区域做像素差检查（关闭动效，允许 H.264 色彩转换误差），均通过。
- 验证中文、日文、特殊字符、显式换行、过长文字拒绝、颜色校验、预览不修改草稿/不调用模型、模板持久化和非法缩略图。
- 浏览器选择荧光挑战、再切换竞技斜切；字号 0.9 / 位置 0.16 保存为 V6，刷新后保留，实际渲染预览成功；三个真实缩略图加载成功。
- 后端 40 项、前端 12 项回归；类型、Lint 和生产构建验证结果记录在发布清单。
