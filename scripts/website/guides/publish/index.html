操作教程

第一次把切片发到平台

账号在设置里配一次。切片页勾选平台即可。默认「仅自己」，方便先试。步骤写在这页，改了不用发客户端。

01 · 打开设置 → 发布

  1. 01

    桌面端右上角打开设置，左侧选「发布」。海外平台和 B 站都在这一页。

  2. 02

    视频仍在你电脑上处理。只有最终成片会上传：海外走 Upload-Post，B 站用本机 Cookie 投稿。

02 · 海外平台：Upload-Post

  1. 01

    打开 app.upload-post.com 注册。

  2. 02

    在 Manage Users 建一个 profile，把要发的社交账号连上去。

  3. 03

    到 API Keys 生成密钥，贴回 AutoClip，点「保存并校验」。

  4. 04

    发布页默认「仅自己」：TikTok 为 SELF_ONLY，YouTube 为 private。公开会直接出现在账号上。

03 · B 站：三个 Cookie

  1. 01

    用 Chrome 或 Edge 打开 bilibili.com 并登录。

  2. 02

    按 F12（Mac 可用 ⌥⌘I）打开开发者工具，选 Application（有的浏览器叫「应用」）。

  3. 03

    左侧 Cookies → https://www.bilibili.com。复制这三个名字的值：SESSDATA、bili_jct、DedeUserID。

  4. 04

    贴成一行 SESSDATA=…; bili_jct=…; DedeUserID=…，回到设置里保存并校验。

只留在这台电脑

Cookie 只保存在本机，不会进仓库或官网。过期或换号时，重新登录再复制三个字段即可。

04 · 在切片上发布

  1. 01

    打开项目，在切片上点「发布」。勾选平台，可见范围先留「仅自己」，再开始发布。

  2. 02

    封面可以一键生成。生图失败或没配模型时，会自动截帧，不会卡住投稿。

  3. 03

    B 站定时要晚于现在两小时。成片画幅跟着账号走：有竖屏账号就渲成 9:16，只发 B 站时按横屏。

常见问题

Cookie 提示无效怎么办？

重新登录 B 站，再从 Application → Cookies 复制三个字段。不要从请求头整段乱贴；缺一个字段就会校验失败。

还没有 profile？

先在 Upload-Post 创建一个 profile，并连接要发布的账号，再回 AutoClip 刷新账号。

封面失败会挡住发布吗？

不会。生图失败或还没生成时，投稿会用截帧封面，流程继续走完。
